# আমার হিসাব (Amar Hisab)

বাংলা-ভাষার ব্যক্তিগত দেনা-পাওনা হিসাব অ্যাপ। React + TypeScript + Vite, IndexedDB/Dexie, PWA এবং ঐচ্ছিক Supabase সংযোগ।

## এখন কী কাজ করে

- দেনা ও পাওনার হিসাব যোগ করা; একই নামের ব্যক্তি আগে থাকলে সেই ব্যক্তির রেকর্ড ব্যবহার করা
- আংশিক/সম্পূর্ণ পরিশোধ ও আদায় রেকর্ড করা
- অবশিষ্ট টাকা ও ড্যাশবোর্ডের হিসাব স্বয়ংক্রিয়ভাবে করা
- নাম/ফোন দিয়ে খোঁজা, লেনদেনের ইতিহাস দেখা
- IndexedDB-তে লোকাল স্থায়ী সংরক্ষণ; সাধারণ রিফ্রেশ/ব্রাউজার বন্ধের পরেও ডেটা থাকে
- JSON ব্যাকআপ ডাউনলোড এবং ব্যাকআপ থেকে তথ্য যোগ করা
- PWA service worker-এর মাধ্যমে অ্যাপ shell ক্যাশ করা; প্রথমবার অ্যাপ লোড করার পর পুনরায় অফলাইনে খোলার জন্য ডিজাইন করা
- Supabase-এ লগইন এবং লোকাল রেকর্ড আপলোডের প্রাথমিক ম্যানুয়াল সিঙ্ক
- অর্থের হিসাব integer পয়সায় রাখা, ওভার-পেমেন্ট ঠেকানো এবং গণনার unit test

## গুরুত্বপূর্ণ সীমাবদ্ধতা

এই সংস্করণটি ব্যবহারযোগ্য local-first ভিত্তি, কিন্তু এখনই সম্পূর্ণ উৎপাদন-প্রস্তুত cloud sync নয়। বর্তমান সিঙ্ক লোকাল রেকর্ড Supabase-এ আপলোড করে; অন্য ডিভাইস থেকে ডেটা pull/merge, দ্বন্দ্ব শনাক্তকরণ/রিভিউ, ব্যর্থ queue retry এবং পূর্ণ automatic background sync এখনো সম্পূর্ণ নয়। একাধিক ডিভাইসে ব্যবহার করার আগে এই অংশগুলো সম্পন্ন ও পরীক্ষা করতে হবে। Supabase সেটআপ না করলে অ্যাপটি লোকাল মোডে চলে।

এটি আর্থিক রেকর্ডের জন্য; প্রথমে নমুনা তথ্য দিয়ে পরীক্ষা করুন এবং নিয়মিত JSON ব্যাকআপ রাখুন।

## চালানোর পদ্ধতি

প্রয়োজন: Node.js 20 বা তার পরের সংস্করণ।

```bash
npm install
npm run dev
```

টার্মিনালে দেখানো লোকাল URL (সাধারণত `http://localhost:5173`) ব্রাউজারে খুলুন।

Production build ও test:

```bash
npm test
npm run build
npm run preview
```

## Supabase সেটআপ

1. Supabase-এ একটি private project তৈরি করুন।
2. SQL Editor-এ `supabase/migrations/001_initial_schema.sql` ফাইলের SQL চালান।
3. Authentication-এর Email/Password চালু করে নিজের account তৈরি করুন। public registration বন্ধ রাখার নীতি dashboard-এ সেট করুন; account invitation/প্রশাসনিকভাবে তৈরি করা উত্তম।
4. Project URL এবং publishable/anon key `.env` ফাইলে লিখুন (`.env.example` থেকে কপি করুন)। কখনো `service_role` key ব্রাউজারে দেবেন না।
5. অ্যাপ পুনরায় চালু করুন, সেটিংসে ইমেইল ও পাসওয়ার্ড দিয়ে লগইন করুন।
6. এই সংস্করণে সিঙ্ক বোতাম লোকাল রেকর্ড আপলোড করে; cross-device restore/merge সম্পূর্ণ না হওয়া পর্যন্ত এটিকে একাধিক ডিভাইসের নির্ভরযোগ্য একমাত্র কপি হিসেবে ব্যবহার করবেন না।

## iPhone X-এ ইনস্টল

1. অ্যাপটি HTTPS-এ deploy করে iPhone-এর Safari-তে URL খুলুন। localhost development URL সরাসরি অন্য ডিভাইসে ব্যবহার করা যাবে না।
2. Safari-তে Share বোতাম চাপুন → **Add to Home Screen** → Add।
3. হোম স্ক্রিনের আইকন থেকে খুলুন। অফলাইনে অ্যাপ shell খুলতে প্রথমে অনলাইনে একবার অ্যাপ লোড হতে হবে।

## কম্পিউটারে ব্যবহার

ডেপ্লয় করা HTTPS URL Chrome/Edge/Safari-তে খুলুন। সমর্থিত ব্রাউজারে Install app/Add to Home Screen অপশন ব্যবহার করা যায়। লোকাল development-এর জন্য `npm run dev`।

## অফলাইন ও ব্যাকআপ

রেকর্ড IndexedDB-তে লোকাল ডিভাইসে থাকে এবং বেসিক হিসাব ইন্টারনেট ছাড়াই হয়। অন্য ডিভাইসে লোকাল ডেটা নিজে থেকে দেখা যাবে না, যতক্ষণ না পূর্ণ সিঙ্ক ব্যবস্থা চালু করা হয়। সেটিংস → ব্যাকআপ নিন থেকে JSON ফাইল সংরক্ষণ করুন। ফিরিয়ে আনার সময় ফাইলের রেকর্ড বর্তমান ডেটার সঙ্গে যোগ হবে; একই ID থাকলে সেই রেকর্ড আপডেট হবে।

## Data model

- `people`: ব্যক্তি ও যোগাযোগের তথ্য
- `debts`: ধার নেওয়া মূল হিসাব
- `receivables`: ধার দেওয়া মূল হিসাব
- `payments`: দেনা পরিশোধ ও পাওনা আদায়ের পৃথক transaction ledger
- `syncQueue`: সিঙ্কের জন্য লোকাল pending change-এর ভিত্তি

Amount values are stored as integer paisa (minor units); display is formatted as Bangladeshi Taka.
